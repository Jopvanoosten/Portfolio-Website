Wat was dit project?

Voor mijn tweede informatica-project in VWO 6 werkte ik samen met een teamgenoot aan een webapplicatie. Dit project ging verder dan mijn eerste website-project door het combineren van frontend- en backend-technologie. We gebruikten Flask, een Python web framework, om een functionele applicatie te bouwen met database-integratie.

Wat ik heb geleerd

  • Frontend-backend communicatie via HTTP-requests
  • Backend-development met Python en Flask
  • Database ontwerp en management
  • Samenwerken in een team-omgeving
  • Web application deployen op cloudplatforms
  • API-design en integratie

Mijn proces

We begonnen met het definiëren van de vereisten en het ontwerp van het systeem. Het project was verdeeld in frontend- en backend-taken. Ik werkte aan het frontend-design en -implementatie, terwijl mijn teamgenoot zich op de backend-logica concentreerde. Regelmatig communiceerden we om ervoor te zorgen dat alles goed integreerde.

Het grootste uitdaging was het leren begrijpen van hoe frontend en backend samenwerken. Ik moest leren hoe je data naar een server stuurt, hoe je responses verwerkt en hoe je interface-updates gebaseerd op die data kunt doen. Dit project gaf me inzicht in full-stack webontwikkeling en het belang van teamwerk en communicatie bij softwareontwikkeling.
