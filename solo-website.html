Wat was dit project?

Voor mijn informatica-project in VWO 5 wilde ik een professionele website maken met modern design en interactieve elementen. Dit project was mijn eerste echte stap in webontwikkeling en hielp me te begrijpen hoe websites in elkaar steken.

Wat ik heb geleerd

  • Semantische HTML-structuur opbouwen
  • Styling met CSS en responsive design
  • Interactiviteit toevoegen met JavaScript
  • Versiebeheersing met GitHub
  • Website deployen via GitHub Pages

Mijn proces

Ik begon met het ontwerpen van de structuur en het definiëren van de lay-out. Daarna werkte ik stap voor stap aan de styling om alles er professioneel uit te laten zien, en voegde ik JavaScript toe voor interactieve functies zoals menu's en formulieren.

Dit project leerde me het belang van clean code, een goed ontwerp en gebruikersgerichtheid. Het was ook mijn eerste ervaring met versiebeheersing via GitHub en het deployen van een live website.
